# Development history

`history/` preserves the project's original intent, specification, plans, incident notes, and reviews. `validation/` preserves historical fixtures and check results. These dated records may be in Chinese and describe older versions; they are retained as evidence, not the current user guide.

The current product behavior is documented in the root English README, usage, compatibility, and privacy guides. Workstation-specific root paths were replaced with placeholders in current public copies. Git history is retained; it has not been rewritten. Old records may reference their original artifact locations or synthetic dates.

New public examples are in `examples/`, and new reproducible local runs write to ignored `local-test-vaults/` rather than overwriting historical records.
